# 4 - Lacos de repeticoes
IMPORTANTISSIMO
A variavel declarada para ser o indice do bloco de repeticao (neste caso, o 'i')
esta variavel continua existindo apos sair do bloco, o que significa que, se for utilizado
dois blocos de repeticoes que usam a mesma ideia, o valor nao reseta.
Entretanto, eh possivel forcar o indice inicial.
Exemplo
for indice in vetor:
    ...

for indice in outro_vetor:
    ...
Neste caso, o valor de indice sera o ultimo utilizado.


for i in range(5): #Conta de 0 a 4 # Primeiro indice eh zero
    print(i)

for i in range(1,6): # Conta de 1 (inicio) a 5. Ou seja, sexto indice ---> 6-1 = 5
    print(i)

for i in range(5,0,-1): #Comeca de 5, vai ate 0, decrementando.

SEPARANDO INPUT : Quando UMA STRING tem mais de uma informacao desejada
Exemplo : A string "GIRAR ESQUERDA"
Para pegar as informacoes individuais GIRAR e ESQUERDA, use:
x = "GIRAR ESQUERDA"
resultado = x.split() #Separa a string usando os espacos como referencia
#Resulta em um collection de strings.

Dicas para strings : Eh interessante formatar a string toda antes de separar as informacoes.
    "upper()" transforma todos os caracteres em letras maiusculas.
    "split()" remove todos os espacos em brancos. Eh possivel eliminar um caractere especifico.
OBS - Usar split ANTES do upper causa erro, pois o resultado do split eh uma collection, e nao uma string
OBS - Os metodos de formatacao anteriormente NAO altera a string da variavel "pai".
Ordem ideal : strip().upper().split()
